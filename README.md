## 🚀 Projects & Experience

### 1. 아웃바운드 영업 사원 업무 효율화 플랫폼 (국방부 창업경진대회)
* **역할**: 플랫폼 기획 및 백엔드 개발
* **내용**: 아웃바운드 영업 사원들의 업무 프로세스를 분석하여 효율성을 높일 수 있는 맞춤형 플랫폼 기획 및 개발.

* **역할**: 시스템 개발 및 로직 구현

### 3. 패혈증 최적 치료 방안 연구 (UC Irvine)
* **내용**: 빅데이터 분석 및 DQN 알고리즘을 활용하여 패혈증 환자의 최적 치료 경로를 탐색하는 연구 참여.

### 4. MR 기반 3D 최적 경로 탐색 (Kent State University)
